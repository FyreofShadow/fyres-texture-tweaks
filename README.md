# Fyre's Texture Tweaks

A texturepack made by FyreofShadow for Gregtech: New Horizons, combining some old favorites from Zedtech and Modernity with some brand new textures to keep more aligned with the vanilla GT:NH feel. Proper credits will always be added for any textures that were ripped from or inspired by other packs.

# THIS REPO AND README ARE A WORK IN PROGRESS.

For now, download the pack using the Code => Download as ZIP feature (if there's anything there). This will most likely need to be unzipped and rezipped from what I've heard.

# Credits

[Modernity for GT:NH](https://github.com/ModernityGTNH/Modernity-GTNH/tree/main) - Inspiration for some highlighting effects on casings, user feedback from their discord was of great help as well

[Zedtech-GT:NH](https://www.curseforge.com/minecraft/texture-packs/zedtech-gtnh) - Too many items to count, multiblock casing and coil texture inspiration, detailing on singleblock machine casings, machine faces

[Zederrian Technology GT5U](https://github.com/MCTian-mi/Zederrian-Technology-GT5U) - An old project of mine directly forked from this was an indirect inspiration for this pack (thanks Tian_mi for letting me do that original fork!)

[Unity 1.3.2 for Minecraft 1.7.10](https://www.curseforge.com/minecraft/texture-packs/unity/files/2369895) - Iron Ingot and Brick textures used for GT:NH-specific materials and machines
